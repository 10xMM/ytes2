# IPTV Server for Switch (NRO)
Build: install devkitPro + libnx, run `make` -> iptv-switch.nro
Or push to GitHub: Actions builds the .nro for you (Artifacts).
Install: copy to sdmc:/switch/iptv-switch/iptv-switch.nro
Controls: A open server, X change address, + exit.
Run hbmenu via Album (applet mode) - web browser applet doesn't work in title-override mode.
